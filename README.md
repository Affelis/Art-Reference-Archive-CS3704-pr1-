This is an Art Reference Archive, it is made for artists who want to use their own references during praktice, but can't find an app that would combine reference management and practice features in one.

Art Reference Archive allows to upload images and give them castom tags. Next user could request a random image and provide tags that this image has to have. Image could be changed by clicking random button again. Also the app can make a slide show of references with provided tags, such that picture would change after amount of time set by the user. User also could see all pictures with chosen tags in the Gallery. If no tags are provided, it is assumed that any picture would suit.

To run the Art Reference Archive, you need to have Python3 installed and Flask library. It could be run by command "Python3 app.py" called from the same repository where app.py is located. The page would apper on localhost.

The "uploads" folder and "data.json" already contain some pictures and their description for testing. They could be deleted through app interface, or by deleting all contants of "uploads" and replacing contant of "data.json" by []
